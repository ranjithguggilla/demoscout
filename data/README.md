# Data

`spotify_songs.csv` is downloaded on demand by `demoscout fetch` (or automatically by `demoscout run`).
It is not committed; the file is about 8 MB.

Source: the TidyTuesday week 4 release of 2020, built from the Spotify API with the spotifyr package.
https://github.com/rfordatascience/tidytuesday/tree/main/data/2020/2020-01-21
